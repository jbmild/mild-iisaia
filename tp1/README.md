# TP 1 — Hola mundo

Página de saludo en un solo archivo HTML, con CSS embebido y etiquetas semánticas.

## Cómo se ejecuta

Abrir `index.html` con doble click, o arrastrarlo a un navegador.

## Qué me propuse construir

Una página **Hola mundo** en HTML y CSS, sin JavaScript, usando etiquetas que describen cada parte del documento (`header`, `main`, `section`, `footer`).

Todavía no es la entrega completa: es el primer artefacto para empezar el TP1.

## Decisiones que tomé yo

Pendiente de confirmar. En este primer prompt el agente eligió:

- Un solo archivo (`index.html`) con el CSS adentro de `<style>`, siguiendo el paradigma *single-file* de la semana 2. Alternativa: un `.html` y un `.css` separados.
- Estructura semántica aunque la página sea mínima: `header` + `h1`, `main` + `section` + `p`, `footer`. Sin `<div>`.
- Variables CSS para paleta y espaciado, para poder cambiar el tema después sin reescribir reglas.
- Sin `<nav>`: una página de saludo no tiene destinos que merezcan un menú.
